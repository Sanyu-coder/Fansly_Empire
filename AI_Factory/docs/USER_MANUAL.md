## 1. システムの全体像と起動・終了方法

本システムは、ローカル環境（Ollama + ComfyUI + NudeNet + Playwright）を使い、**「画像生成 → 選別＆画像モザイク → I2V動画生成＆動画モザイク → Fansly予約投稿」**までを一気通貫で行うコンテンツ生産工場です。  
DM営業自動化アプリ（`AI_DM_Sales` / ポート `5051`）とは完全に独立しているため、**2つのアプリを同時に立ち上げて並列稼働**できます。

### 1.1 起動と終了の手順（事前準備）

* **起動前の必須確認（2つのエンジン）**
  1. **ComfyUI** が起動していること（画像生成・高画質化・I2V動画生成に使用）。
  2. **Ollama** が起動していること（シチュエーション企画・英語キャプション・日英翻訳に使用）。
* **コンソールの起動方法（ワンクリック）**
  1. `C:\Fansly_Empire\AI_Factory\console_app_起動.bat` をダブルクリックします。
  2. 専用の独立ブラウザウィンドウ（`http://127.0.0.1:5050`）が自動で立ち上がります。
* **終了方法**
  * 各ライン（第1ライン・動画バッチ・第2ライン）が稼働中でないことを確認し、ウィンドウを閉じます。稼働中に止めたい場合はヘッダーの **`[⏹ 強制停止]`** を押してください。

### 1.2 画面の共通ヘッダー（常駐メニュー・ライン実行パネル）

| ボタン・表示項目 | 役割・操作内容 |
| :--- | :--- |
| **🎭 キャラ切替ドロップダウン** | 作業対象のキャラクターを切り替えます。フォルダ・予約一覧・ライン稼働はすべて選択中キャラに切り替わります。 |
| **`[⚙️]`（キャラ設定）** | 選択中キャラの表示名、Fanslyハンドル、画像/動画ワークフロー、固定タグ、キャラ口調プロンプトを編集します。 |
| **`[➕ 新キャラ]`** | 新しいキャラクター（別アカウントIP）と専用フォルダ一式をワンクリックで作成します。 |
| **工程タブ（Step 1 / Step 2 / タイムライン）** | 現在の工程を切り替えます。バッジの数字は「今その工程で作業待ちになっている件数」です。 |
| **回数プルダウン ＋ `[🏭 第1ライン稼働]`** | 指定した回数（1回〜20回）だけ連続で画像セット＆英語キャプションを自動生成します。 |
| **`[🎬 動画バッチ稼働]`** | Step 1 を完了して待機中の案件について、ComfyUI（I2V Wan2.2）で動画を一括生成します。 |
| **`[🚀 第2ライン稼働]`** | タイムライン（予約待ちキュー）に入っている完成済み投稿を、Fanslyへ全件まとめて予約投稿します。 |
| **`[⏹ 強制停止]` / `[📟 ログ]`** | 稼働中ラインの緊急停止、および裏側のリアルタイム進行ログの開閉を行います。 |

## 2. 新キャラクター追加 ＆ 初期設定手順

### 2.1 新キャラクターの追加（`➕ 新キャラ`）

1. ヘッダー左上の **`[➕ 新キャラ]`** をクリックします。
2. 以下の項目を入力して **`[✨ キャラクターを作成]`** を押します：
   * **キャラID**: 半角英数字とアンダースコアのみ（例：`luna_cybermaid`）※フォルダ名になります。
   * **表示名**: コンソールとタイムラインに表示される名前（例：`Luna CyberMaid 🩵`）。
   * **Fanslyハンドル名**: `@` から始まるアカウントID（例：`@lunacybermaid`）。
   * **画像生成 ComfyUI ワークフロー**: `workflows` フォルダ内のJSONを選択。
   * **キャラクター設定・口調プロンプト**: キャラの性格・一人称・ファンの呼び方・好みの絵文字などを記述。
3. 作成すると `C:\Fansly_Empire\AI_Factory\characters\<キャラID>\` 配下に専用フォルダ一式が自動生成されます。

### 2.2 既存キャラの設定・ワークフロー編集（`⚙️`）

* キャラ切替ドロップダウン横の **`[⚙️]`** を押すと、途中からでも以下を変更・保存できます：
  * **画像生成ワークフロー** / **FYP動画生成（I2V）ワークフロー** の差し替え
  * **固定ハッシュタグ**（スペース区切り・全投稿の末尾に自動付与されるタグ）
  * **キャラクター性格・口調プロンプト**（タイムラインでの日本語→英語変換やキャプション生成に反映）
  * **シーン企画システムプロンプト**（第1ラインのシチュエーション生成ルール）

## 3. 「1本道コンベア」3工程の操作手順

v3.0 では、**「1つの案件は今やるべき1つの工程にだけ表示され、完了ボタンを押すと即座に次の工程へ移動する直線コンベア方式」**を採用しています。

### 3.1 第1ライン稼働（画像＆キャプション量産）

1. ヘッダーで対象キャラを選択し、回数プルダウン（例：`3回`、`5回`、`10回`）を選びます。
2. **`[🏭 第1ライン稼働]`** をクリックすると、バックグラウンドでシチュエーション企画・英語キャプション1本（短文/中文ローテーション）・追加タグ3種・無修正画像（`_SD.png` / `_HQ.png`）の量産が始まります。
3. 1セット生成が終わるごとに **Step 1** の一覧へ自動で追加されます。

### 3.2 Step 1：画像採用・陰部モザイク・動画ベース1枚必須選択

生成された無修正画像の中から、採用画像と動画化する1枚を決める工程です。

1. 左リストから未処理の候補フォルダ（`No.001` 等）を選択します。
2. **① 採用画像の選択**: 投稿に添付したい画像カードをクリックして **`✔ 採用`** にします（0枚でも可。ダブルクリックまたは `🔍 拡大` でズーム確認できます）。
3. **② 陰部モザイクの適用（必要な画像のみ）**:
   * **陰部が露出している採用画像**については、画像モザイクエディタを開いて陰部領域にモザイクを適用します（`*_MOSAIC.png` が生成されます）。
   * *(※乳首のみの露出や健全画像は、本編用画像ではモザイク不要です)*
4. **③ 動画ベース画像の1枚必須指定**:
   * 動画の元絵にしたい画像カードの **`[🎬 動画ベース指定]`** ボタンを押します（全投稿で動画1本が必須のため、**未選択の状態では保存ボタンが押せません**）。
5. **`[💾 保存してStep2へ]`** をクリックします。
   * 押した瞬間に Step 1 の一覧から消え、動画生成キューに登録されて **Step 2** へ移動します。
   * *(※全体的にイマイチなフォルダは **`[🗑️ 全てボツ]`** を押すと `99_rejected` へ移動して除外されます)*

### 3.3 Step 2：動画バッチ稼働・再生確認・2レイヤーAIモザイク

Step 1 を通過した案件について、動画を生成・確認し、1回の操作で本編用＆FYP用の2本の動画を仕上げる工程です。

1. **動画の一括生成**: ヘッダーの **`[🎬 動画バッチ稼働]`** をクリックし、キューに入った全案件のI2V動画を連続生成します。
2. **動画の再生チェック**: Step 2 一覧から案件を選び、生成された動画（`video_output.mp4`）を再生して動きや破綻がないか確認します。
3. **2レイヤーAIモザイク（1回操作で本編用＆FYP用を同時出力）**:
   * 動画モザイクエディタを開くと、AI（NudeNet）が部位を自動検出して色分け枠を表示します（ドラッグ移動・リサイズ・新規枠追加・削除が可能）。
     * **🔴 赤枠（陰部 / GENITALIA）**: 本編・FYPの **両方** にモザイクがかかります。
     * **🟡 黄枠（乳首 / BREAST_EXPOSED）**: **FYP（無料プレビュー）のみ** にモザイクがかかります（本編では無修正）。
   * 枠の位置を確認したら **`[💾 本編＆FYPを一括作成]`** を1回クリックします（健全動画の場合はモザイク不要、やり直したい場合は **`[🔄 モザイクをリセット]`**）。
4. **`[✅ 完了してタイムラインへ]`** をクリックします。
   * 押した瞬間に Step 2 から消え、英語キャプション・ハッシュタグ・既存の予約と被らない空き枠日時が自動セットされて **タイムライン** へ移動します。

### 3.4 タイムライン：課金/未課金視点プレビュー ＆ 最終編集

Fansly に実際に投稿される見た目と予約スケジュールを最終確認・微調整する工程です。

1. **課金者視点 ⇄ 未課金/FYP視点の切り替え確認**:
   * 画面上部の **`[🔓 課金者視点（本編） ⇄ 🔒 未課金/FYP視点（無料プレビュー）]`** トグルを切り替えます。
   * **課金者視点**: 本編動画（陰部のみモザイク）＋ 採用画像が表示され、陰部モザイク漏れがないか最終チェックします。
   * **未課金/FYP視点**: FYP無料プレビュー動画（陰部＋乳首の両方にモザイク）が表示され、FanslyのFYP規約違反（乳首・陰部の露出）がないか最終チェックします。
2. **右ペインでの最終調整**:
   * **予約投稿日時の微調整**: 空き枠自動セットボタン、または任意の日時・手動時刻枠を選択して変更可能。
   * **日本語入力 → キャラ口調で英訳**: キャプションを変えたい場合、日本語でニュアンスを入力して翻訳ボタンを押すと、そのキャラクターの口調プロンプトを反映した英語キャプションへ変換されます。
   * **候補へ差し戻す**: 作り直したい場合は差し戻しボタンで候補工程へ戻せます。

### 3.5 第2ライン稼働（Fanslyへの完全無人予約投稿）

タイムラインで最終チェックが終わった予約待ち投稿を、Fansly へ一括予約登録します。

1. ヘッダーの **`[🚀 第2ライン稼働]`** をクリックします。
2. Playwright 専用ブラウザが立ち上がり、`02_ready_to_post` 内の予約待ちキューを古い日時順から全件自動で処理します：
   * ① 本編メディア（本編動画＋採用画像）をアップロード
   * ② プレビューサムネから本編動画を自動照合し、`+ Add free preview` に **FYP用動画（健全動画の場合は無修正動画）** を紐付け
   * ③ `Post to FYP` スイッチを `ON` に設定
   * ④ `Schedule` モーダルで予約日時をセットして確定
   * ⑤ 完了後、フォルダを `03_posted` へ自動アーカイブ
3. **⚠️ 実行中の注意**: 第2ライン稼働中はPlaywrightがブラウザ上のマウス座標やキーボード操作を自動制御するため、**完了ログが出るまでそのブラウザウィンドウに触らないでください**。

## 4. モザイク基準と自動3パターン判定ルール（重要）

アカウントBANと法規制リスクをゼロにするため、以下の二重基準で自動出力されます。

| 動画の露出パターン | エディタでの枠設定 | 本編用動画（有料サブスク枠） | FYPプレビュー用動画（無料拡散枠） |
| :--- | :--- | :--- | :--- |
| **パターン①：陰部＋乳首あり** | 🔴 赤枠（1個以上）<br>🟡 黄枠（1個以上） | `*_MOSAIC.mp4` を自動生成<br>（**陰部のみ**モザイク） | `*_FYP_PREVIEW.mp4` を自動生成<br>（**陰部＋乳首**にモザイク） |
| **パターン②：乳首のみあり** | 🔴 赤枠（0個）<br>🟡 黄枠（1個以上） | **無修正の元動画**をそのまま使用<br>（画質劣化なし） | `*_FYP_PREVIEW.mp4` を自動生成<br>（**乳首のみ**モザイク） |
| **パターン③：完全健全動画** | モザイク未編集<br>（またはリセット済） | **無修正の元動画**をそのまま使用 | **無修正の元動画**をそのまま使用<br>（本編と同一ファイル） |

## 5. 日常の運用ルーティン（作業スケジュール目安）

* **夜勤前・就寝前（仕込み：所要時間 約1分）**
  1. ComfyUI と Ollama が起動していることを確認し、`console_app_起動.bat` でコンソールを開く。
  2. 回数を指定（例：`5回`〜`10回`）して **`[🏭 第1ライン稼働]`** を押し、寝ている間に画像セットを自動生産させておく。
* **起床後・スキマ時間（選別＆モザイク：所要時間 約10〜15分）**
  1. **Step 1** で採用画像・陰部モザイク・動画ベース1枚を選んで保存。
  2. **`[🎬 動画バッチ稼働]`** を回してI2V動画を一括生成。
  3. **Step 2** で完成動画を確認し、赤枠・黄枠の2レイヤーモザイクを1回適用してタイムラインへ送る。
* **仕上げ（最終チェック＆予約確定：所要時間 約3分）**
  1. **タイムライン** で「課金者視点 ⇄ 未課金/FYP視点」を切り替えてモザイク漏れがないか目視確認。
  2. **`[🚀 第2ライン稼働]`** を1回押し、全件が Fansly へ予約投稿されたら完了！

## 6. 🆘 困ったときのトラブルシューティング（逆引き早見表）

| 症状・困りごと | 原因 | 解決手順 |
| :--- | :--- | :--- |
| **コンソール画面が開かない** | ポート `5050` のPythonサーバーが停止している。 | `C:\Fansly_Empire\AI_Factory\console_app_起動.bat` をダブルクリックして起動する。 |
| **第1ラインや動画バッチがエラーで止まる** | ① ComfyUI または Ollama が起動していない。<br>② GPUメモリ（VRAM）が一時的に逼迫している。 | ① ComfyUI と Ollama を起動してから再実行する。<br>② ComfyUI 側の「Unload Models / Free Memory」を押すか、ComfyUI を再起動してから再度実行する。 |
| **Step 1 の「保存してStep2へ」ボタンが押せない** | 動画ベースにする画像が1枚も指定されていない。 | v3.0 では全投稿で動画1本が必須です。画像カードの **`[🎬 動画ベース指定]`** ボタンを1枚だけ選択すると押せるようになります。 |
| **動画モザイクでAIの枠がズレる・検出漏れがある** | 激しい動きや特殊なアングルでNudeNetが自動検出しきれなかった。 | モザイクエディタのキャンバス上で既存の🔴赤枠・🟡黄枠をドラッグして位置・サイズを調整するか、「新規枠追加」ボタンで手動で枠を被せてから保存してください。 |
| **第2ライン稼働時にFanslyのログイン画面で止まる** | 対象キャラクターの `browser_profile` のログインセッションが期限切れになっている。 | 一旦 `[⏹ 強制停止]` を押し、対象キャラの `browser_profile` を指定したChrome（または初回ログイン手順）で Fansly に手動ログインし直してから第2ラインを再実行してください。 |
| **第2ラインの途中でマウスを動かして予約が失敗した** | 自動ブラウザ操作中に手動操作が干渉した。 | 失敗した案件は `02_ready_to_post` に残ったままなので、ブラウザに触らずに再度 **`[🚀 第2ライン稼働]`** を押せば続きから自動再開します。 |
