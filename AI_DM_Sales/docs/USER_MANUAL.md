## 1. システムの全体像と起動・終了方法

本システムは、FanslyのDM受信・顧客分析・雑談・PPV（有料限定コンテンツ）提案・クロージング・追撃までを24時間全自動で行うAI営業コンソールです。

投稿自動化アプリ（`AI_Factory` / ポート `5050`）とは完全に独立しているため、**2つのアプリを同時に起動して並列稼働**できます。

### 1.1 起動と終了の手順

* **起動方法（ワンクリック）**

  1. `C:\Fansly_Empire\AI_DM_Sales\run_dm_sales_起動.bat` をダブルクリックします。

  2. 専用の独立ブラウザウィンドウ（`http://127.0.0.1:5051`）が自動で立ち上がります。

  * *(※ローカルAIの翻訳・返信機能を使うため、PC上で **Ollama** が起動している状態にしておいてください)*

* **終了方法**

  * コンソールの専用ブラウザウィンドウ右上の **`×` ボタンを閉じるだけ**で、裏側の監視ブラウザ（Playwright）やバックグラウンドワーカーも自動的に `stop_all()` でクリーン終了します（※ページの再読み込み `F5` では終了しません）。

### 1.2 画面の共通ヘッダー（常駐メニュー）

どのタブを開いていても、画面最上部に以下の操作ボタンが常に表示されます（ウィンドウ幅を狭めた際も自動で綺麗に折り返し表示されます）。

| ボタン・表示項目 | 役割・操作内容 | 
| ----- | ----- | 
| **`[▶ 全キャラ一括稼働]` / `[⏹ 全停止]`** | 全キャラクターの**AI自動返信・PPV自動送信・自動追撃**を一斉にON/OFFするマスタースイッチです。<br>※**`OFF`（停止）の状態でも、Fansly DMの巡回監視・新着DM取得・日本語翻訳・AI顧客カルテ更新は常時継続**され、人間による手動返信のみ可能な「監視・手動モード」として動作します。 | 
| **キャラクター切替メニュー（展開式）** | クリックすると全キャラの一覧が開きます。表示するキャラの切り替え（または「全キャラ横断表示」）と、**各キャラ名のすぐ横にある個別稼働ON/OFFトグル**（`OFF` 時は監視のみ継続・自動返信停止）を操作できます。 | 
| **`💤` バッジ（キャラ横）** | 現在そのキャラクターが「睡眠時間スケジュール」に入っており、自動返信を一時保留している目印です。 | 
| **`[⚙️ 設定]`** | 初期価格マスター、**AI返信待機時間（ランダム遅延秒数範囲）**、睡眠時間設定、Fansly手動ログイン、自己進化・休眠掘り起こしのクイック実行、および最下部の **`[📖 運用マニュアルを開く]`**（検索機能付き）を開きます。 | 
| **`[＋ PPV素材追加]`** | 新しい動画・画像をドラッグ＆ドロップでPPV武器庫へ登録するモーダルを開きます。 | 

## 2. 初回セットアップ（新しいキャラを追加したとき）

新しいキャラクターを追加した直後、またはFanslyのログインセッションが切れた場合は、最初に一度だけ手動ログインを行います。

### 2.1 Fansly アカウントへの手動ログイン連携

1. 画面右上の **`[⚙️ 設定]`** をクリックします。

2. 「Fanslyアカウント連携」欄のプルダウンから **ログインさせたいキャラクター** を選択します。

3. **`[🔑 ブラウザを開いて手動ログイン / 再認証]`** をクリックします。

   * *(※裏でそのキャラのボットが稼働中だった場合は自動で一時停止します)*

4. 専用Chromeウィンドウが立ち上がり、Fanslyのログイン画面（またはDM画面）が開きます。

5. 通常通りID・パスワード（および2段階認証）でログインし、**`https://fansly.com/messages`（DM一覧画面）が表示されたことを確認してから、そのChromeウィンドウの `×` を閉じてください**。

6. これで `C:\Fansly_Empire\AI_DM_Sales\profiles\<キャラID>` にログイン状態が保存され、次回からはログイン不要で自動巡回できるようになります。

### 2.2 初期価格マスター・AI返信待機時間・睡眠時間の確認

同じ **`[⚙️ 設定]`** モーダル内で以下を確認・調整します。

* **Step 1〜3 初期価格マスター**: PPVを新規追加したときに自動入力されるデフォルト金額（基本価格・お試し割引・太客価格）を設定します。

* **⏱️ AI返信待機時間（受信文字数比例 ＆ 人間味ランダム遅延範囲）**:
  * 新着DMを検知した際、即レスによるボット感を防ぐために待機する **最短秒数（`min_reply_delay_sec`、初期値 `60` 秒）〜 最長秒数（`max_reply_delay_sec`、初期値 `300` 秒）** に加え、以下の文字数基準を画面から自由に変更・保存できます：
    * **短いメッセージ基準（`short_msg_chars_threshold`、初期値 `20` 文字）**: この文字数以下の短文には最短待機時間付近でテンポ良く返信します。
    * **長いメッセージ基準（`long_msg_chars_threshold`、初期値 `150` 文字）**: この文字数以上の長文にはしっかり読んで返す最長待機時間付近で返信します（中間は線形補間＋±15%のランダムゆらぎ）。

* **睡眠時間スケジュール**:

  * 初期値は **`OFF`**（時間帯 `19:00` 〜 `22:00` JST ※北米深夜の閑散時間帯）です。

  * 24時間フル稼働させたい場合は `OFF` のまま、人間らしい就寝時間を演出したい場合は `ON` に切り替えて保存します（睡眠中に届いたDMは、起床時刻後に順次返信されます）。

* **🚀 S.E.L.L. 営業ステージ突破閾値設定（10〜100 pt / 手動調整対応）**:
  * 営業フェーズの遷移はptベースの閾値で制御されています。各フェーズの閾値は `[⚙️ 設定]` モーダル内で手動入力・変更できます：
    * **1_Icebreak → 2_Explore（初期値 40 pt）**: 挨拶・関係構築フェーズから好み深掘りフェーズへ移行するための閾値。
    * **2_Explore → 3_Lead_Pitch（初期値 70 pt）**: 好み深掘りフェーズから提案誘導フェーズへ移行するための閾値。
    * **3_Lead_Pitch → 4_Lock_Close（初期値 85 pt）**: 提案誘導フェーズからクロージングフェーズへ移行するための閾値。
  * 範囲は 10〜100 pt（5pt刻み推奨）。変更後は `[💾 閾値のみ即時保存]` または `[💾 設定を保存]` を押して反映します。
  * モニタリング画面では、各顧客ごとの現在のスコア・閾値・残りptがリアルタイムゲージで表示され、AIがどのくらいで次フェーズへ移行するかを直感的に確認できます。

## 3. 4つのメインタブの使い方

### 3.1 タブ1：営業モニタリング（メイン司令室・4秒自動リアルタイム更新）

日常の稼働状況・売上・チャット履歴の確認と、手動介入を行うメイン画面です。**手動リロード不要で4秒ごとに自動更新**され、オペレーターが入力欄に文字を打っている最中も入力内容が消えないよう自動保護されます。

* **上段（コンパクトサマリーカード）**: 本日のDM売上（USD）、PPV成約率（CVR）、対応中顧客数、省エネ降格顧客数、要介入＆未返信放置アラート件数、稼働ステータス（`🟢 自動営業中` ／ `👁️ 監視継続 (手動のみ)`）を表示します。

* **中段（緊急停止・未返信放置アラート枠）**:

  * ファンが危険ワード（`refund`, `scam`, `bot`, `AI`, `minor` 等）を送ってきた場合や、手動切替後に10分以上未返信のまま放置されたスレッドが赤/黄アラートとして強調表示されます。

  * **`[手動対応済みにする（AI再開）]`**: 内容を人間が確認し、問題なければロックを解除してAI営業を再開します。

  * **`[この客を永久ミュート]`**: 悪質客・スパム客に対して今後一切AIが反応しないように永久ブロックします。

* **右ペイン上部（返信待機カウントダウン ＆ 手動切替・自動復帰バー）**:

  * **待機カウントダウン**: AIが既読遅延・タイピング待機中の間、**`⏳ 自動返信まで残り XX秒（送信予定 HH:MM:SS）`** が1秒単位でリアルタイム表示されます。
  * **`[⏭️ スキップして手動返信へ]`**: 待機中のAI自動返信を即座にキャンセルして「手動対応保留中」へ切り替え、下部の日本語介入入力欄に自動フォーカスします。
  * **`[🤖 やっぱりAI自動返信に戻す]`**: 手動対応保留中にこのボタンを押すと、即座にAI自動返信カウントダウンを再セットして自動営業へ復帰します。
  * **⚠️ 返信忘れ防止ガード**: 手動切替のまま **10分以上未返信** になると、左ペインのスレッド一覧と右ペイン上部に **`⚠️ 手動返信待ち（未返信放置）`** アラートバッジが点滅表示されます（手動送信するか「AI自動返信に戻す」を押すと自動解除されます）。

* **下段（左右2ペインのチャットタイムライン）**:

  * **左ペイン（スレッド一覧）**: 最新メッセージ順に顧客が並び、残り秒数バッジ・手動保留バッジ・未返信バッジ・累計課金額・営業フェーズが一目で分かります。

  * **右ペイン（会話ログ ＆ AI顧客カルテ ＆ 検討ログ ＆ 直接介入ボックス）**:

    * **会話吹き出し ＆ 送信済みPPVサムネイル／ホバー詳細ツールチップ**:
      * すべてのメッセージが **上段：英語原文** ／ **下段：日本語訳** の2段で常時表示されます。
      * AIまたは手動でPPV素材（画像・動画）を送信したメッセージには、吹き出し内に**実際に送信したPPVのサムネイル画像／動画プレイヤー（ロック価格・開封状況バッジ付き）**が描画されます。
      * サムネイルに**マウスオーバー（ホバー）**した時だけフローティング情報カードが浮かび上がり、その素材の **「ファイル名・段階（導入/本命/超秘蔵）・価格・属性タグ・売り込みメモ・開封状況（未購入/購入済）」** をスマートに確認できます（クリックすると音声付き拡大ライトボックスで再生可能）。

    * **リアルタイムAI顧客カルテ（日本語）**: 会話からAIが自動抽出した「好み・フェチ」「心理タイプ」「推定予算感」「反応の良い話題」「メモ」が日本語で表示されます。

    * **`🧠 AIカルテ根拠・返答検討ログを見る`（展開式アコーディオン・スクロール＆高さリサイズ対応）**:
      * カルテのすぐ下をクリックすると開閉でき、**「① どの発言からどの好み・心理・予算感を抽出したか」** と **「② なぜそのフェーズ・階段ステップ・A/Bルール・チップ/PPV判断を選んだか」** の思考過程を確認できます。
      * 内容が長くなっても見切れないよう縦スクロールバー（`overflow-y: auto`）が付いており、右下のハンドルをドラッグしてパネルの高さを自由に広げることも可能です。

    * **S.E.L.L. ステージゲージ（リアルタイム突破進捗）**:
      * 検討ログパネル上部には、現在どの営業フェーズにいるか（例: `1_Icebreak` / `2_Explore` / `3_Lead_Pitch` / `4_Lock_Close`）、現在の突破スコア（pt）、次のフェーズの閾値、残りpt、スコア算出理由（`score_reason_ja`）がプログレスバー付きで表示されます。
      * ファンとの会話に応じてptが加算され、閾値に達すると自動的に次フェーズへ昇格します。昇格時には「🔥 ステージ突破済」バッジが表示されます。
      * 表示される情報はリアルタイムで更新され、直近ターンのスコア推移も過去ログとして確認可能です。

    * **`💎 PPV提案・開封履歴`（ファイル名クリックで直接ジャンプ）**:
      * 右下の提案履歴や吹き出し内フッターに表示される **`💎 ファイル名 ↗` リンクをクリック**すると、即座に **タブ2（「💎 2. PPV武器庫一覧」）** へ切り替わり、該当するPPV素材カードまで自動スクロール＋ハイライト強調表示されます。

    * **オペレーター直接介入ボックス（手動PPV選択 ＆ ダイナミックプライシング送信対応）**:
      * 日本語で返信内容を入力して送信すると、ローカルLLMが**キャラクターの口調に合わせた自然な英語へ自動変換**し、Fanslyへ直接送信します（稼働スイッチが `OFF` の状態でも手動送信可能です）。
      * 下段の **`💎 手動PPV送信`** バーから任意のPPV素材を選択すると、**ミニサムネイルプレビュー**が表示されるとともに、そのファンの顧客カルテ（節約層 / 標準層 / 太客VIP層）から自動計算された **🎯 AI推奨ダイナミック価格** が自動セットされます（プルダウンからお試し・標準・太客VIPプリセットへの切替や金額の自由手入力も可能）。プリセット切替時は `お試し割引（節約・初回層）` / `標準価格（通常層）` / `太客VIP価格（高予算層）` の3種から選択でき、選択に応じて推奨価格が自動計算されます。送信するとPlaywrightボットの送信キューを通じてFansly実機のPPVロック価格モーダル経由で送信されます。

### 3.2 タブ2：PPV武器庫一覧（左右黒帯ゼロ・2カラムコンパクト一覧 ＆ Vision AI再解析）

登録済みの有料販売用コンテンツ（動画・画像）の一覧管理・成績分析画面です。

* **左右黒帯ゼロの「左サムネ＋右編集」2カラムレイアウト ＆ 拡大ライトボックス**:
  * 各カードは「左ペイン：縦長比率にピタリとフィットする黒帯ゼロのメディア枠（`object-fit: cover`）」＋「右ペイン：実績・階段・3種価格・タグ・メモをコンパクトに集約した編集枠」の横並び2カラム構造になっており、ウルトラワイド画面では2〜3列で多くの素材を一目で比較できます（画面幅を狭めた際は自動で縦積みへ切り替わります）。
  * **サムネイルをクリック**すると、画面中央の**拡大ライトボックス**が開き、画像全体や**音声・シークバー付きの動画**をノンクロップで大きく再生・確認できます（`ESC` キー・背景クリック・閉じるボタンで終了）。

* **絞り込み・並び替え**:
  * 階段レベル（`すべて` / `Step 1` / `Step 2` / `Step 3`）やメディア種別（`動画` / `画像`）、5種ソート（`売上金額高い順` 等）で稼ぎ頭をすぐに特定できます。

* **カード操作・3段階価格自動連動・Vision AI再解析**:
  * カード内の **`① 階段レベル`（Step 1: 導入 ／ Step 2: 本命 ／ Step 3: 超秘蔵）を変更すると、そのキャラクターの初期価格マスターに対応する3種の価格（お試し・基本・太客）が自動的に価格欄へ切り替わります**。
  * 既存のPPV素材に対しても、カード内の **`[✨ AIでタグ・メモを自動生成]`** ボタンを押すだけでローカルVision LLMが画像/動画を再解析し、自然な日本語の **「属性タグ」** と **「売り込みメモ・フック文」** を自動生成してDBへ反映します。手動微調整後は **`[💾 変更保存]`** を押すと確定します。

### 3.3 タブ3：キャラ・プラン設定 ＆ 自己進化・休眠掘り起こし

キャラクターの人格・サブスクプラン定義と、Phase 2の売上最大化機能を管理する画面です。

1. **キャラクターペルソナ設定（`dm_persona.json`）**:

   * 表示名、口調・絵文字スタイル、一人称、ファンの呼び方、NGトピック、営業スタンスを編集して保存します。

2. **サブスクプラン階層設定（`plans.json`）**:

   * 無料フォロワー（`free_follower`）や各有料プラン（`silver_vip`, `gold_goddess` 等）の月額、特典範囲、上位プランへのアップセル誘導文句を設定します。

3. **🧬 自己進化営業ルール ＆ A/Bテスト状況（Phase 2機能）**:

   * システムは新規ファンを **Group A（現行本番ルール）** と **Group B（新検証ルール）** に 50:50 で自動振り分けし、成約率（CVR）を自動計測します。

   * **`[🔄 今すぐ勝ち/負け会話を分析して新ルールBを生成]`** ボタンを押すと、過去の「売れた会話」と「逃げられた会話」をAIが比較分析し、新しい営業鉄則ルール（日本語解説＋英語プロンプト）を生成します。

   * 十分なサンプルが貯まり Group B の成約率が Group A を上回ると、自動的に Group B が新しい本番ルールへ昇格します。

4. **💌 休眠課金ファン掘り起こし（Phase 2機能）**:

   * 「過去に課金歴あり」かつ「7日以上連絡が途絶えている」優良ファンを自動抽出します。

   * **`[🚀 休眠ファンへ個別再会DMを送信]`** を押すと、各ファンの日本語顧客カルテ（過去の好みや話題）を織り込んだ完全パーソナライズDMをAIが生成し、送信キューへ投入します。

### 3.4 タブ4：営業シミュレーター（本番パイプライン完全共通テスト画面）

実際のファンに送信する前に、AIの営業トーク・価格判定・PPV選定根拠を安全に試し打ちできるテスト画面です（**本番環境と100%共通の推論パイプライン**で動作します）。

* 左上でキャラクターとテスト客の条件（加入プラン、累計課金額、連続無視回数、現在フェーズ、適用A/Bプレイブック群）を設定します。

* 下部の入力欄で **`[✨ 日本語を英語に変換して送信]`** を押すと、日本語で打ったテスト客のセリフを「ファンらしい英語」に変換した上で、本番と全く同じ営業エンジンが応答を返し、PPV提案時には吹き出し内に**ロック価格付きPPVサムネイル（ホバー詳細カード付き）**も描画されます。

* 右ペインには判定インスペクターに加えて、モニタリング画面と同じ展開式アコーディオン **`🧠 AIカルテ根拠・返答検討ログを見る`**（縦スクロール＆高さリサイズ対応）が配置されており、**「なぜこの回答・価格・PPVを選んだのか」** をシミュレーション中もリアルタイムで検証できます。

## 4. PPV素材の登録手順（`[＋ PPV素材追加]` ＆ Vision AI自動解析）

新しい動画・画像をAIに販売させるための登録手順です（`AI_Factory` で生成した素材もそのまま登録できます）。

1. 画面右上の **`[＋ PPV素材追加]`** ボタンをクリックします。

2. 中央のドロップ枠に、登録したい動画（`.mp4` 等）または画像（`.jpg`, `.png` 等）をドラッグ＆ドロップします。

3. ドロップと同時に、**ローカルOllamaのVision（画像認識）モデル（`qwen2.5vl` 等）が画像や動画の代表フレームを自動解析**し、以下を自然な日本語で自動入力します：

   * **階段レベル（最重要）**:
     * `Step 1（導入）`: 挨拶・軽めのチラ見せ用（初課金のハードルを下げる素材）
     * `Step 2（本命）`: Step 1 購入者や熱量の高い客へ提案するメイン素材
     * `Step 3（超秘蔵）`: 太客・VIP向けの最高単価プレミアム素材

   * **価格3種（USD）**: 選択したStepに応じて初期価格マスターから自動入力されます（個別変更も可）。

   * **推奨属性タグ（日本語 `tags_json`）**: 衣装・色・場所・ポーズ・雰囲気など、AI営業エンジンがファンの好みに合わせてPPVを選びやすくなる具体的な日本語タグ（例：`ランジェリー, 黒レース, 寝室, 自撮り, 甘え`）。

   * **売り込みメモ・フック文（日本語 `description_memo`）**: どんな見どころの素材で、どのタイミングでどう煽ると売れるかの日本語メモ（＋英語誘い文句 `pitch_hint`）。**`[✨ AIでタグ・メモを自動生成]`** ボタンでいつでも再解析できます。

4. **`[＋ PPV武器庫へ登録]`** を押すと、`ppv_vault\` フォルダおよび `empire_core.db`（`ppv_vault` テーブル）へ自動保存され、即座にAIの営業武器庫へ追加されます。

   * 登録と同時に、PPV素材の**全画面ぼかしプレビュー画像**が `ppv_vault\previews\<素材名>_blur.jpg` に自動生成されます。これはサムネイル表示時に細部がわからないようシルエットを隠すための処理で、メディアの1枚目フレームに強いガウシアンぼかしを適用しています。既存素材の一括再生成も `app/services/media_blur_service.py` 経由で実行可能です。

## 5. 裏側で動いている全自動営業の仕組み（知っておくべきルール）

作業者が手動操作しなくても、ボットON中は以下のルールでAIが自動判断を行います。

### 5.1 S.E.L.L. 6段階営業フェーズ

| フェーズ名 | AIの振る舞い | 
| ----- | ----- | 
| **`1_Icebreak`（挨拶・関係構築）** | 新規ファンの1往復目では必ず雑談・褒め・共通の話題で距離を縮め、PPVや価格の話は一切出しません。 | 
| **`2_Explore`（好み・フェチ深掘り）** | 2往復目（3往復未満）では相手の好み・求めているシチュエーションを自然に聞き出して顧客カルテへ記録し、いきなりPPV提案へ飛び級しないよう保護されています。 | 
| **`3_Lead_Pitch`（提案誘導）** | 3往復以上の関係構築後（または既課金リピーター）に、好みに合致する未購入PPVへの期待感を高めます。 | 
| **`4_Lock_Close`（クロージング）** | 特別感を伝えつつ、実際のメディアファイルをロック付き（指定価格）でDM送信します。 | 
| **`5_Cooldown`（余韻・非催促）** | PPV送信直後や見送り直後は**「早く開けて」「まだ買ってないの？」等の急かし・催促を一切行わず**、余裕のある甘い雑談で余韻を楽しみます（リマインドは6〜12時間後の専用ワーカーのみが1回実行）。 | 
| **`6_Low_Priority`（省エネ降格）** | **「無料フォロワー かつ PPV提案を2回連続スルーした客」** は自動降格し、GPU節約のため数時間おきに超短文の相槌のみを返します。 | 

### 5.2 動的プライシング（客層別の自動価格切り替え）

同じPPV素材でも、相手のこれまでの課金実績に応じて提示金額を自動最適化します。

* **初課金前（累計 `$0`）**: **`お試し割引価格（Tripwire）`** を提示し、最初の1回を買わせるハードルを下げます。

* **通常リピーター（累計 `$0.01 〜 $49.99`）**: **`基本価格（Base）`** を提示します。

* **太客・最上位プラン加入者（累計 `$50.00` 以上）**: **`太客価格（Whale）`** を提示し、1件あたりの単価を最大化します。

### 5.3 階段式PPV ＆ 自動追撃（FOMO・Step 2・チップ誘導）

* **既購入PPVの完全除外**: すでに購入したコンテンツを同じ客へ二度提案することはありません。

* **未開封FOMOリマインド**: PPV送信後 **6〜12時間経過しても未開封** の客に対し、「恥ずかしくなってきたから今日中に消しちゃうかも…」等の希少性リマインドを **1回だけ** 自動送信します。

* **Step 1 購入後の Step 2 追撃**: Step 1 の購入（開封）を検知すると、熱量が高いうちに続編となる **Step 2** を自動提案します。

* **チップ（投げ銭）誘導フック**: ファンから強い称賛や特別リクエストが出た際や購入直後の感謝タイミングで、自然に `$5〜$10` のチップをねだるフックを挟みます。

* **人間味演出（待機秒数カスタマイズ対応）**: 受信後すぐに即レスせず、`[⚙️ 設定]` の **「⏱️ AI返信待機時間（人間味ランダム遅延範囲）」** で指定した最小秒数〜最大秒数（初期値：60〜300秒）の間でランダムな待機カウントダウン＆タイピング演出を挟んで送信します。

### 5.5 PPV 選定スコアリング（2層マッチング）

ファンが「○○が見たい」と言ったとき、AIはどの PPV を推薦するかを **2層スコアリング** で決定します。

#### スコアリングの仕組み

| 層 | ソース | 重み | 説明 |
|----|--------|------|------|
| **Layer 1** | `category_tags`（カテゴリ別マスタータグ） | **1個あたり +2点** | 手動で PPV カードに付けるタグ（play / body_outfit / situation の各カテゴリから最大1個ずつ）。運営が意図的に付けたタグなので確信度が高く、重みが大きい。 |
| **Layer 2** | `pitch_hint`（視覚フック説明・日本語） | **1個あたり +1点** | AI が VL で自動生成した視覚描写文（例:「女性がベッドでオナニーしている。全裸で、乳首と陰部が見えている…」）。ファンが言ったキーワード（自由語）がこの文中に部分一致するたびに +1 点。 |

#### 耳役 LLM の役割

ファンの DM を耳役 LLM が分析し、以下の2つを抽出します：

1. **`matched_tags`**: master_tags.json に定義されたタグ ID（例: `bedroom`, `lingerie`）→ Layer 1 の照合用
2. **`unmatched_needs`（自由語）**: ファンが言った視覚特徴の日本語キーワード（例: `全裸`, `オナニー`, `濡れ`, `密着`）→ Layer 2 の照合用

#### 具体例

ファン: `"I want to see you naked masturbating in the bedroom"`

耳役 LLM の抽出結果:
- `matched_tags`: `["bedroom"]`（master_tags の situation カテゴリ）
- `unmatched_needs`: `["全裸", "オナニー", "寝室"]`（自由語）

| PPV | category_tags | pitch_hint | Layer 1 | Layer 2 | **合計** |
|-----|--------------|-----------|---------|---------|---------|
| A | situation=寝室 | 「女性が王座に座っている」（全裸・オナニーなし） | 寝室✓ = **2** | 寝室✓ = **1** | **3** |
| B | (空) | 「女性がベッドで**全裸**で**オナニー**している。**寝室**」 | 0 | 全裸✓+オナニー✓+寝室✓ = **3** | **3** |
| C | (空) | 「女性がベッドで**全裸**で**オナニー**している。**寝室**で**密着**アングル」 | 0 | 全裸✓+オナニー✓+寝室✓ = **3** | **3** |

→ A, B, C が同点（3点）の場合、**Layer 1（手動タグ）が優先**されるため **A が推薦される**。
→ B と C が同点の場合、pitch_hint の詳細度は同じなので ppv_id で決定論的に選択される。

#### 設計のポイント

- **master_tags は固定（26個）**: 自由語（全裸・オナニー等）は master_tags に追加せず、pitch_hint 文中的の部分一致でマッチさせるため、タグの乱雑化を防ぐ。
- **手動タグが空でも推薦可能**: category_tags を付けなくても、pitch_hint にファンの要望が含まれていれば Layer 2 のみでスコアが付き、PPV が推薦される。
- **同点時の優先順位**: ① 総スコア降順 → ② Layer 1（手動タグ一致数）降順 → ③ ladder_step の近さ → ④ ppv_id
- **除外ルール**: 購入済み（`is_unlocked=1`）は永久除外。未購入で直近7日以内に提案済みのものは除外（7日超で再提案可能）。

#### 作業者がやること

- **category_tags の手動入力**: タブ2「PPV武器庫一覧」の各カードで、play / body_outfit / situation の3カテゴリから各1個ずつタグを選択して `[💾 変更保存]` を押す。これを付けると Layer 1 の +2 点が加わり、推薦されやすくなる。
- **pitch_hint の確認・微調整**: VL が自動生成した日本語視覚フック（`pitch_hint`）を確認し、必要なら手動で修正する。ここが Layer 2 のマッチングソースなので、正確な視覚描写ほどファン要望に当たりやすい。

### 5.4 パッシブ監視モード（自動復旧・ハートビート）

アプリ起動中は、バックグラウンドで常時DM巡回監視が行われています。ブラウザがクラッシュしたり通信が途切れたりした場合でも、システムが自動的に監視を復旧させます。

* **ハートビート監視**: 監視ワーカーは5秒ごとにハートビートを出力し、アプリが生存していることを内部で確認しています。
* **自動ブラウザ復旧**: Playwrightのブラウザコンテキストが閉じたことを検知すると、自動的に新しいブラウザセッションを起動して監視を再開します。
* **ウォッチドッグ**: アプリ起動中は独立したウォッチドッグスレッドが全キャラの監視状態を15秒ごとに確認し、ハートビートが90秒以上途絶えたキャラを自動再起動します。
* **監視履歴**: 監視ステータスには `last_heartbeat_at`（最終ハートビート）, `consecutive_poll_failures`（連続失敗回数）, `restart_count`（再起動回数）, `last_restart_reason`（再起動理由）が表示され、不具合時の原因特定に役立ちます。

## 6. 日常の運用ルーティン（作業スケジュール目安）

* **朝・稼働開始時（所要時間：約3分）**

  1. `run_dm_sales_起動.bat` でコンソールを開く（すでに常時稼働中の場合はブラウザをリロード）。

  2. タブ1「営業モニタリング」で **要介入アラート枠（赤枠）** に通知が来ていないか確認し、必要に応じて手動返信または解除を行う。

  3. 稼働対象キャラのトグルが `ON` になっていることを確認する。

* **昼〜夕方（必要に応じて：約5分）**

  1. `AI_Factory` で新しく作った画像・動画があれば、`[＋ PPV素材追加]` から武器庫へ補充する。

  2. タブ2「PPV武器庫一覧」を「売上金額高い順」に並べ替え、反応が悪いPPVの `pitch_hint`（売り込みヒント）や価格を微調整する。

* **週1回（メンテナンス：約5分）**

  1. タブ3「キャラ・プラン設定」を開き、**`[🔄 今すぐ勝ち/負け会話を分析して新ルールBを生成]`** を押して営業ルールを進化させる。

  2. 同じくタブ3の **休眠ファン掘り起こし** の候補人数を確認し、対象がいれば個別再会DMを送信する。
